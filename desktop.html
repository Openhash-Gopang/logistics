Platform Overview

K-Logistics란?

K-Logistics는 고팡(Gopang) 생태계의 물류 담당 AI 서비스입니다. 현재는 (1) 화물차 등록·운송업 허가·물류센터 인허가 등 행정 민원 안내와, (2) 개인간 화물 운송 카풀형 매칭 두 가지 기능을 실제로 제공합니다.

  • 행정 민원 안내 → 화물차 등록, 운송업 허가, 물류센터 인허가 절차를 AI가 안내
  • 화물 운송 매칭 → 수거지·배송지를 게시하면 인근에서 활동 중인 기사에게 실시간 알림, 응답·수락·GDC 결제까지 지원(traffic.hondi.net과 매칭 인프라 공유)

고팡의 PDV(Private Data Vault)와 OpenHash를 통해 결제 기록은 위·변조 불가능하게 저장됩니다. 대규모 창고 자동 배분, 실시간 재고 관리, 산업 공급망 통합 같은 기능은 아직 개발되지 않았습니다.

STEP 01

수요 게시

수거지·배송지·화물 정보를 등록하면 시스템이 게시합니다.

DEMAND POSTED
STEP 02

인근 기사 실시간 알림

등록된 기사 중 인근에 있는 사람에게 실시간으로 알림이 갑니다.

REAL-TIME NOTIFY
STEP 03

매칭 확정 · GDC 결제

기사가 응답하고 화주가 수락하면, 완료 후 GDC로 직접 결제합니다.

GDC SETTLEMENT
Why K-Logistics

현재 제공하는 것과 제공하지 않는 것

과장된 비교표 대신, 지금 실제로 되는 것과 안 되는 것을 정직하게 정리합니다.

항목 현재 상태
화물차 등록·운송업 허가 안내 제공 중 ✓ (webapp.html)
개인간 화물 매칭(카풀형) 제공 중 ✓ (실시간 알림·GDC 결제 포함)
결제 기록 위변조 방지 제공 중 ✓ (PDV·OpenHash)
창고·재고 자동 관리 미제공 — 개발 계획 없음
운임 자동 경매·협상 미제공 — 화주·기사가 직접 협의

Use Cases

활용 시나리오 (개발 목표)

아래는 측정된 실적이 아니라, 현재 매칭 인프라를 바탕으로 앞으로 확장하려는 방향입니다.

농수산물 개인간 운송
소규모 농가가 인근 화물차주와 카풀형으로 매칭해 직접 운송을 협의하는 시나리오. 냉동·냉장 창고 자동 예약 기능은 없습니다.
구상 단계
소규모 사업자 긴급 운송
급한 소량 화물을 근처 화물차주와 실시간으로 연결. 자동 대체 공급사 탐색 같은 기능은 없고, 매칭만 지원합니다.
현재 가능
개인간 소포·물품 배송
이커머스 라스트마일 자동화는 없지만, 개인이 근처 이동 중인 화물차주에게 소포 운송을 요청하는 용도로 지금 사용할 수 있습니다.
